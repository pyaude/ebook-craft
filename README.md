# 重页 REPAGE

把扫描 PDF 转成可搜索、可复制的重新排版 PDF 和可重排 EPUB。本地网页应用，不需要云端 API、付费服务或 GPU。适合以中英文横排正文为主的扫描书。

## 启动

需要 Python 3.10–3.13。macOS / Linux：

```bash
./scripts/start.sh
```

打开 http://127.0.0.1:8000 。首次启动会安装依赖并从霞鹜文楷官方仓库下载开源中文字体；OCR 的检测、方向分类和识别 ONNX 模型包含在 RapidOCR 包中。完成安装后，转换不需要联网。自定义端口：`PORT=8080 ./scripts/start.sh`。

Windows 或手动安装：

```bash
python -m venv .venv
# Windows：.venv\Scripts\activate
# macOS / Linux：source .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/setup_font.py
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

## 使用

1. 上传 PDF，设置扫描文件的实际页码范围（从 1 开始，结束页留空表示全部）。建议先识别 3–5 页，检查质量后再处理全书。
2. 默认先识别纸张边界与文字方向，可靠时校正透视及倾斜，然后重新 OCR。可切换「原始扫描 / 校正后扫描」对照。短文本的行列对齐关系用于推断姓名网格；网格以统一列宽、行距重新排版，不使用扫描绝对坐标。可逐格修改姓名，或把误判的网格切回正文。文本区中每行表示一排，Tab 分隔列。
3. 按页查看原图和 OCR 文字。可修改文字，把段落设为正文、标题、网格或忽略。低于 85% 的置信度标橙色，这不是准确率保证。
4. 新上传的文件会自动检测并裁切插图，在「本页插图」查看缩略图，选择保留、插入位置及图片说明。旧任务点击「检测插图」可补检测，无需重跑 OCR。漏检或裁切不完整时，点击「手动框选」，在原页上拖出矩形，再点击「裁切并加入」；可取消旧裁切的保留开关。插图会嵌入 PDF/EPUB，按指定的段落位置排列。
5. 需要额外保留复杂页面时，仍可勾选「导出时附上本页扫描图」，或导出时附上全部原页。未识别出文字和插图的页面自动保留原图。
6. 保存校对，选择 PDF 纸张、字号与行距，导出 PDF / EPUB。导出前也会自动保存校对。EPUB 包含导航目录和中文字体，实际字体和行距可由阅读器覆盖。

文件、原页图片、带坐标和置信度的 OCR 结果、校对结果及下载文件保存在 `data/<任务ID>/`。刷新页面或重启服务后可以从最近书籍重新打开已完成的任务。取消在当前页推理结束后生效，已完成页面可导出。服务重启会把未完成任务标记为中断；当前版本需重新提交剩余页码，不支持自动续跑。

## 技术构成

- **开源代码和模型**：[RapidOCR](https://github.com/RapidAI/RapidOCR) 的 `rapidocr-onnxruntime==1.2.3`，内含 PaddleOCR 系列文本检测、文字方向分类和中英文识别模型，使用 ONNX Runtime 在 CPU 推理。本项目固定使用已经在当前 Python 3.13 环境实测的发行包，不是最新模型。
- **PDF 读取**：[pypdfium2](https://github.com/pypdfium2-team/pypdfium2) / PDFium，把 PDF 页转成像素图；限制长边 3000 像素以控制内存。
- **自行编码**：任务队列、持久化、保守的双栏识别、按行坐标重建段落、标题规则、校对界面、导出流程与 API。
- **PDF 排版**：[ReportLab](https://www.reportlab.com/)，嵌入中文 TrueType 字体，自动换行分页与页码。
- **EPUB**：自行实现的 Python 标准库打包器，生成 EPUB 3 容器、导航、章节、样式与字体。
- **中文字体**：[霞鹜文楷](https://github.com/lxgw/LxgwWenKai)，SIL OFL 1.1，授权文本保存在 `assets/OFL.txt`。
- FastAPI 后端 + 原生 HTML/CSS/JavaScript 前端，无前端构建步骤。

## 扫描校正与结构恢复

- 新任务默认开启，可在上传时取消「自动校正倾斜与透视」（仍会推断文字结构）。旧任务点击「重新校正与识别（新副本）」，从原 PDF 重新处理；原任务、逐字校对及手动插图不会被覆盖，新副本不继承旧校对。
- 透视校正需要检测到占画面主要区域、与背景有明显对比的纸张四边形，并检查 OCR 文字不会被裁掉；证据不足时保留原图，不猜测纸张四角。
- 倾斜校正使用至少 4 条可靠文字框的方向共识，自动处理约 0.25–12 度的小角度旋转，扩展画布避免切边。每次几何变换后重新 OCR，插图也从校正后的页面裁切。
- 保存原始渲染 `raw-N.jpg`、校正结果 `page-N.jpg` 和变换矩阵、角度、校正说明。界面显示本页实际是否应用校正，而非一律显示成功。
- 连续短文本行按水平/垂直对齐关系识别网格，允许中间缺格；单行多姓名也保留为一排。OCR 合并为一行且姓名间仍有空格时可以拆分；完全粘连且无分隔的姓名暂不自动切分。缺格保持空白并提示核对，不编造姓名。PDF 使用表格布局，EPUB 使用 XHTML 表格，因此阅读器缩放时仍保持行列关系。
- 这是平面校正与规则化结构恢复，不处理书页弯曲/书脊曲面展平，也不保证恢复所有混合多栏、复杂跨格表格或原书字体。两栏正文目前恢复阅读顺序，不保证输出为同样的双栏外观。

## 上下文智能校对

OCR 完成后，在「上下文智能校对」中检测模型，选择当前页或整本书，点击「分析错字」。结合本页段落、相邻段落和前后页上下文生成局部修改建议，保留原始 OCR 行、位置、置信度及修改历史，不改变已有插图和网格版式。应用后的文字用于 PDF / EPUB 导出。

- 默认逐条确认，也可批量应用。勾选「分析后自动应用保守修改」后，只自动应用变化不超过两个字符、原短语至少四个字符且不含受保护符号的建议。这是启发式限制，不代表模型判断一定正确。
- 跳过标题、姓名网格和忽略项；提示模型不改人名、引文和术语；程序拦截数字/英文/常见数学符号变化、来源不匹配、含糊的重复短语和大幅改写。正文内的人名和术语不能可靠自动保护，仍需人工检查。
- 支持停止、忽略建议及撤销本轮修改。应用后又手动编辑同段时，拒绝整段撤销以保护人工修改；可以展开段落下的校对记录查看修改前文本。新一轮分析替换建议列表，已应用的历史仍保留。
- 自动应用期间暂停本页编辑；保存使用版本检查，防止旧页面覆盖新校对。手动编辑后，旧建议会被拒绝，请重新分析。

安装 [Ollama](https://ollama.com/download)，单独启动本地模型服务：

```bash
./scripts/start_model.sh
```

在另一个终端下载模型（约 1 GB，首次需要联网）：

```bash
ollama pull qwen2.5:1.5b
# 若使用本项目内已下载的运行时：
# .tools/ollama/ollama pull qwen2.5:1.5b
```

脚本仅监听本机，关闭 Ollama 云端功能，模型保存在忽略提交的 `data/ollama-models/`。已有 Ollama 服务的用户可直接使用现有服务；不要同时启动占用相同端口的第二个服务。应用只连接本机 HTTP 地址（默认 `http://127.0.0.1:11434`，可通过 `OLLAMA_URL` 配置本机其他端口），并拒绝云端模型。分析时不发送书籍到外部服务。

轻量模型可能漏检或误改，复杂书籍可自行选择已下载的、更大的本地模型（需更多内存，第三方模型许可证各异）。当前按顺序分析，最多排队两个任务；CPU 上整本书处理可能较慢。每次模型请求最多等待 300 秒，失败会显示原因，已生成建议仍保留。

## 当前边界

这是可实际运行的首版工具，精排指重新组织可编辑文字并统一字体、段落和分页，不是逐像素复刻原书。

- OCR 会误识字，尤其是低清晰度、手写、竖排、复杂数学符号；可选本地语言模型辅助校对，但仍可能漏检或改错；默认只生成建议。
- 标题和双栏阅读顺序是几何与规则推断，不是通用文档布局模型；混合多栏、脚注、跨页段落需要校对。页眉页脚可手动设为忽略。
- 插图检测使用 OCR 文字遮罩 + OpenCV 非文字连通区域分析，是几何候选检测，不是语义视觉模型。适合边界清晰的照片、示意图和线稿，但复杂底纹、扫描阴影、漏识文字可能误检，小图、浅色图或分散线稿可能漏检。每页最多 100 张；请核对预览，必要时手动框选。
- 裁切从原始渲染图片生成 PNG，不使用遮掉文字后的检测图，因此图内标注可保留。检测不会自动删除 OCR 文字；如果图内标注被再次识别成正文，可手动设为忽略。多栏图片的插入位置可手动调整。
- 复杂公式和带跨行跨列的表格可作为图片保留，尚不自动恢复为可编辑结构；本次结构恢复针对短文本姓名网格。裁切清晰度取决于扫描源和页面渲染精度。
- EPUB 按来源页面组织章节，以页面中的标题命名目录；不承诺自动恢复全书原有章节层级。
- 默认单个 OCR 工作线程，最多排队 3 个任务；文件最大 300 MB，单次最多 500 页。更长的书可分段处理。
- 当前为单用户本地应用，绑定 `127.0.0.1`。没有账号、访问鉴权或多租户隔离，不应直接部署为公网服务。
